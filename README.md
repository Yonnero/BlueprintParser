# BlueprintParser | Автоматизированная система извлечения данных из конструкторской документации

![Version](https://img.shields.io/badge/Version-0.2.0-blue)
![Python](https://img.shields.io/badge/Python-3.11%2B-green)
![Platform](https://img.shields.io/badge/Platform-Windows%20%2F%20Linux-0078D6)

**BlueprintParser** — это инженерная платформа для автоматического анализа PDF-чертежей (ЕСКД / ГОСТ), извлечения метаданных из основной надписи и формирования сводных ведомостей для производства, технологов, ПДО и ERP-систем.

---

## Ключевые возможности (v0.2.0)

* **Геометрический поиск штампа (ГОСТ 2.104-2006, Форма 1):** локализация основной надписи ($185 \times 55$ мм) и пропорциональный расчет координат ячеек «Наименование» (Графа 1) и «Материал» (Графа 3) с защитой от захвата краевых служебных надписей («Копировал», «Формат»).
* **Многоступенчатое извлечение текста из PDF:**
  * чтение текстового слоя с фильтрацией дублирующихся символов;
  * геометрическая реконструкция строк по центрам символов;
  * извлечение скрытых векторных шрифтов из PDF-аннотаций AutoCAD (`PDFSHX`);
  * автоматическое восстановление сбитой кириллической кодировки (`CP1251` поверх `Latin-1`).
* **Интеллектуальная нормализация материалов:**
  * независимое выделение марки материала и стандарта (`ГОСТ`, `ОСТ`, `ТУ`, `DIN`, `ISO`, `ASTM`);
  * защита от ложных коллизий вложенных марок (`Д16` vs `Д16Т`, `40Х` vs `40Х13`, `08Х18Н10` vs `12Х18Н10Т`);
  * открытый справочник сталей, цветных сплавов и полимеров (`PEEK`, `ABS`, `Фторопласт-4`, `ПА6`, `Силиконовая резина`).
* **Консервативный разбор обозначений и имен файлов:**
  * распознавание типов документов (`Деталь`, `Сборка`, `Спецификация`) с поддержкой кириллических и латинских суффиксов `_СБ` и `_СП`;
  * сохранение буквенных индексов и исполнений в децимальных номерах (`001А`, `-01`, `-02`);
  * дополнительная верификация сборочных чертежей по содержимому Графы 1 штампа.
* **Генерация сводных 📊 Excel-отчетов:**
  * автоматическая группировка и цветовая маркировка по папкам узлов;
  * интерактивные гиперссылки `Открыть` для мгновенного перехода к PDF-файлу чертежа и директории его хранения.
* **Визуальная диагностика (`DebugVisualizer`):** опциональное сохранение вырезок штампа в `.png` с разметкой рамок ячеек и центров символов, а также `.json`-отчетов для быстрой калибровки нестандартных чертежей.

## Архитектура (Clean & Extensible Architecture)

Проект спроектирован с разделением ответственности между слоями данных, бизнес-логики, генерации отчетов и интерфейса (принципы SOLID):

```text
BlueprintParser/
├── .github/
│   └── workflows/
│       └── build.yml            # CI/CD: автосборка бинарников под Windows и Ubuntu
├── core/                        # Ядро системы и бизнес-логика
│   ├── __init__.py
│   ├── version.py               # Единый источник версии и метаданных приложения
│   ├── models.py                # Типизированные модели данных (Blueprint, MaterialResult, MaterialStatus)
│   ├── blueprint_helpers.py     # Нормативная геометрия Формы 1, сборка символов и лечение кодировок
│   ├── materials.py             # Движок сопоставления и нормализации марок материалов
│   ├── debug_visualizer.py      # Рендер отладочных рамок штампа (PNG + JSON)
│   └── analyzer.py              # Координатор конвейера обработки PDF (FilenameParser, TitleBlockLocator, PDFAnalyzer)
├── reports/                     # Генераторы выходных форм
│   └── excel.py                 # Построение, группировка и стилизация таблиц Excel
├── ui/                          # Слой представления
│   └── console.py               # Интерактивный консольный интерфейс (поддержка Drag-and-Drop папок)
├── resources/                   # Внешние ресурсы и справочники
│   ├── app.ico                  # Иконка приложения
│   └── materials.json           # Открытая база эталонных материалов и сигнатур распознавания
├── main.py                      # Точка входа в приложение
├── build.py                     # Кроссплатформенный скрипт сборки в автономный исполняемый файл
├── requirements.txt             # Список зависимостей Python
└── README.md                    # Документация проекта
```

## Быстрый старт (Для пользователей без Python)

Готовые скомпилированные версии программы для **Windows (`.exe`)** и **Linux (Ubuntu)** не требуют установки Python или дополнительных библиотек:

1. Перейдите в раздел **[Releases](https://github.com/Yonnero/BlueprintParser/releases)** репозитория.
2. Скачайте актуальный исполняемый файл (`BlueprintParser_v0.2.0.exe` для Windows).
3. Запустите программу, перетащите папку с чертежами в окно программы мышкой (Drag-and-Drop) и укажите папку для сохранения сводного Excel-файла.

## Запуск из исходного кода и сборка (Для разработчиков)

### 1. Установка зависимостей
```bash
git clone [https://github.com/Yonnero/BlueprintParser.git](https://github.com/Yonnero/BlueprintParser.git)
cd BlueprintParser
python -m venv .venv
# Активация окружения (Windows PowerShell):
.venv\Scripts\Activate.ps1
# Активация окружения (Linux / Ubuntu):
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python main.py
```

### 3. Сборка автономного исполняемого файла (`.exe` / Linux binary)
```bash
python build.py
```
Готовый бинарный файл появится в директории `dist/`.
