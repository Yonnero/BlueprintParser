**BlueprintParser** — это автоматизированная система извлечения данных и подготовки отчетов. 

Платформа решает задачу перевода конструкторской документации (КД) в сводные табличные отчеты для производства и ERP-систем. Текущая сборка фокусируется на анализе PDF-чертежей.

---

## Текущие возможности (Модуль PDF v0.1.0)

* **Разбор обозначений:** Распознавание типов документов (Сборка `_СБ`, Спецификация `_СП`, Деталь). 

* **Генерация сводных 📊Excel-отчетов:** интерактивные гиперссылки для мгновенного открытия чертежей и папок их локализации.

---

## Архитектура (Clean & Extensible Architecture)

Проект спроектирован с упором на масштабируемость и принцип открытости/закрытости (SOLID).

```text
BlueprintParser/
├── core/                   # Ядро системы и бизнес-логика
│   ├── materials.py        # Движок сверки и нормализации материалов
│   ├── models.py           # Универсальные структуры данных
│   └── analyzer.py         # Модуль анализа PDF
├── reports/                # Генераторы выходных форм
│   └── excel.py            # Построение, группировка и стилизация Excel-отчетов
├── ui/                     # Слой представления
│   └── console.py          # Консольный интерфейс
├── resources/              # Внешние ресурсы и конфигурации
│   ├── app.ico             # Иконка приложения
│   └── materials.json      # Открытая база эталонных материалов и regex-сигнатур
├── main.py                 # Точка входа в приложение
├── build.py                # Скрипт автосборки
├── requirements.txt        # Список зависимостей Python
└── README.md               # Документация проекта
